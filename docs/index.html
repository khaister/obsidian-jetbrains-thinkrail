ThinkRail, for Obsidian

A flat, quiet Obsidian theme that follows the design of JetBrains ThinkRail: zinc surfaces, a neon green accent, Geist for text and JetBrains Mono for code. Dark and light.

Install from Obsidian View on GitHub

Style Settings

Install the Style Settings plugin to configure the theme under Settings, Style Settings, JetBrains ThinkRail.

OptionTypeDescription
Property lines Dropdown How the Properties block at the top of a note shows which value belongs to which name: hide lines (default), a solid or dotted line from each name to its value, or zebra striping across every other row.
Property line gap Slider, 0 to 16px (default 2px) Space on each side of the line. Applies to the solid and dotted options.

Fonts

The theme uses ThinkRail's fonts but does not bundle them. Install them on your system and the theme picks them up. Without them it falls back to your system fonts.

  • Geist on Google Fonts
  • JetBrains Mono on Google Fonts

Recommended: download the whole family from each page and install it with its italics. The theme uses weights 400 (Regular), 500 (Medium) and 600 (SemiBold), so install at least those. Restart Obsidian after installing.

On macOS you can install both with Homebrew instead:

brew install --cask font-jetbrains-mono
brew install --cask font-geist
